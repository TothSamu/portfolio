Weblapkészítés

Használt szoftverek és technológiák:

  • Visual Studio Code
  • HTML5
  • CSS3
  • Bootstrap 5
  • JavaScript (alapok)

A weblapkészítés során megismerkedtem a modern weboldalak felépítésének alapjaival, valamint a HTML és CSS nyelvek használatával. Megtanultam, hogyan lehet strukturált és átlátható weboldalakat létrehozni, valamint hogyan lehet a tartalmat különböző stílusokkal esztétikusan megjeleníteni. A Bootstrap keretrendszer használatával képes vagyok reszponzív, különböző képernyőméretekhez igazodó felületeket készíteni. A fejlesztés során gyakorlatot szereztem a hibakeresésben és a kódok rendszerezésében is, amely hozzájárult a hatékonyabb munkavégzéshez és a felhasználóbarát megoldások kialakításához.
